## 1. Step 1 — Product Understanding & Context

### 1.1 Product Type & Core Domain
- **Core Domain**: Elite Engineering Portfolio, Systems Architecture, Industrial IoT Telemetry, and Cybersecurity Research.
- **Product Archetype**: High-Performance Personal Brand & Technical Systems Showcase. Blends high-fashion motorsport editorial composure (inspired by Lando Norris) with rigorous engineering authority (industrial MQTT, Linux kernels, Next.js fullstack platforms, autonomous AI systems).
- **Core Purpose**: Showcase Dimas Adhi P.'s technical duality — the creator of elegant, scalable web software ("ON CODE") and the rigorous builder of real-time industrial hardware, telemetry, and security infrastructure ("IN LAB").

### 1.2 Target Audience & User Personas
1. **Engineering Directors & Tech Recruiters (Primary / 50% Traffic)**:
   - *Needs*: Rapid verification of code rigor, fullstack competency (Next.js, TypeScript, APIs), system architecture mastery, and tangible projects with live deployments.

2. **Industrial IoT, SCADA & Embedded Systems Partners (Secondary / 30% Traffic)**:
   - *Needs*: Proof of real hardware/telemetry implementation (Smart Oil Tracker, MQTT 10Hz pipelines, GPS fleet telemetry, edge sensors).
   - *Behavior*: Toggles to "IN LAB" mode to evaluate telemetry architecture, hardware specs, and protocols.
3. **Cybersecurity & Systems Research Peers (Tertiary / 20% Traffic)**:
   - *Needs*: Inspection of security mindset, Linux container hardening, packet inspection, SAST triage practices.
   - *Behavior*: Evaluates technical precision, monospace readouts, and defensive engineering architecture.

### 1.3 Environment of Use
- **Desktop High-Fidelity Viewing (1280px–1920px+)**: Primary evaluation mode. Immersive perimeter HUD, flowing aerodynamic CFD streamlines, dual-mode split-screen interaction, and multi-column modular showcase cards.
- **Mobile Handheld Inspection (375px–428px)**: Fast mobile review on mobile safari/chrome. Fluid touch controls, sticky perimeter CTA, responsive stacked layout with zero horizontal overflow (`scrollWidth <= innerWidth`).

### 1.4 Information Density & Usage Frequency
- **Information Density**: 6/10 (Balanced Editorial Composure & High-Precision Telemetry Clusters). Wide negative space around monumental typography; dense, crisp monospace parameters inside project cards.
- **Usage Frequency**: Episodic high-intent evaluation during recruitment cycles, client pitches, and technical collaborative inquiries.

### 1.5 Emotional Target & Trust Requirements
- **Emotional Signature**: Relentless technical speed, aerodynamic clarity, calm engineering authority, refined editorial prestige.
- **Trust Requirements**: Verifiable live project links (`smartoil.dindustries.my.id`, `undangan.dindustries.my.id`), honest representation of academic and learning journey, direct access to CV and source repositories.

### 1.6 Prohibited Aesthetics & Clichés (Strict Anti-AI Slop Gate)

## 4. Step 4 — Multi-Direction Exploration

Three distinct visual directions were developed and compared:

### Direction A: "Terminal Brutalist SCADA"
- **Concept**: Pure Linux terminal aesthetic. Pitch-black OLED canvas, green phosphor monospace fonts, ASCII art headers, raw border-collapsed tables.
- **Pros**: Authentic to low-level Linux and cybersecurity.
- **Cons**: Too abrasive and dry; lacks modern executive credibility and ignores Adhi P.'s explicit directive for Lando Norris elegance.

### Direction B: "Aerodynamic Velocity & Editorial Stream" (SELECTED WINNING DIRECTION)
- **Concept**: High-fashion engineering editorial inspired by `landonorris.com`. Deep carbon canvas with flowing SVG CFD streamlines, Mona Sans paired with high-contrast serif italic accents, floating perimeter HUD, dual-mode "ON CODE" vs "IN LAB", modular project cards with notched tab badges, solid Volt Lime `#D2FF00` pill buttons, and an organic contoured arch footer with `DA//04` monogram.
- **Pros**: Exact 1:1 conceptual and aesthetic match to the owner's explicit mandate; elevates an informatics student into a world-class technology talent.

### Direction C: "Cyberpunk HUD Matrix"
- **Concept**: 3D Three.js wireframe sphere, glowing neon cyan/magenta reticles, rotating radar blips, scanline overlays.
- **Pros**: Visually energetic.
- **Cons**: Stereotypical AI slop and cliché sci-fi trope; explicitly forbidden under Fleet UI Diversity Governance.

## 7. Step 7 — Design DNA Specification

### 7.1 Archetype & Product Character
- **Archetype**: High-Performance Engineering & Aerodynamic Editorial.
- **Tone**: Precise, disciplined, kinetic, confident, culturally sharp.
- **Core Identity Monogram**: `DA//04` (Dimas Adhi // Unit 04 / 2026 Season).

### 7.2 Spatial System & Grid
- **Desktop (>=1280px)**: 12-column grid, max-width `1280px` (`max-w-7xl`), `px-6 lg:px-12`.
- **Tablet (768px–1023px)**: 8-column grid, `px-6`.
- **Mobile (<768px)**: 4-column fluid layout, `px-4`, zero horizontal overflow (`overflow-x-hidden`).
- **Vertical Spacing Scale**:
  - Hero Stage: `pt-32 pb-24 md:pt-40 md:pb-32`
  - Section Spacing: `py-24 lg:py-32`
  - Card Gap: `gap-6 md:gap-8`
  - Element Spacing: `space-y-4` to `space-y-8`

### 7.3 Typographic System

### 7.5 Background Aerodynamic Contours (CFD Streamlines)
- Replace static dot-grids and cyan scanlines with an animated/layered SVG vector streamline mesh:
  - 5 to 7 sweeping laminar flow spline curves traversing from top-left to bottom-right.
  - Stroke: `1px` to `1.5px` with gradients fading from `rgba(255, 255, 255, 0.07)` to `rgba(210, 255, 0, 0.05)` and `transparent`.
  - Subtle organic low-opacity depth masses (`rgba(255, 255, 255, 0.02)`) floating underneath, evoking airflow pressure maps.

### 7.6 Signature Elements (The 5 Pillars)
1. **Perimeter HUD Command Shell**:
   - Floating top command capsule with personal monogram `DA//04`, anchor links, and high-vis Volt Lime `#D2FF00` pill button.
   - Floating bottom-left telemetry widget (`CURRENT DISPATCH // LATENCY < 100ms // SINCE 2024`).
2. **Dual-Mode Architecture ("ON CODE" vs "IN LAB")**:
   - High-contrast segmented kinetic toggle slider at the top of the showcase section.
   - "ON CODE": Fullstack web platforms, Next.js 15, TypeScript, real-time SSE, autonomous AI pipelines.
   - "IN LAB": Industrial IoT hardware, SCADA MQTT telemetry, Linux container security & packet inspection.
3. **Modular Showcase Cards with Notched Tab Badges**:
   - Hairline-bordered cards (`1px solid rgba(255, 255, 255, 0.08)`) with recessed image container and technical parameter HUD.
   - Protruding bottom notched tab badge (`[2025 // FULLSTACK]` / `[2024 // SCADA IOT]`) inspired by Lando Norris's helmet gallery metadata tags.
4. **Solid Volt Lime High-Contrast Pill CTA**:
   - Filled solid `#D2FF00`, bold black uppercase text `#0A0A0B`, rounded-full pill shape with subtle lime proximity bloom on hover.
5. **Contoured Dark Footer with Arch Top**:
   - Elegant curved arch top contour (`rounded-t-[40px] md:rounded-t-[60px]`).
   - Infinite kinetic typography marquee: `"ENGINEERING RESILIENT DIGITAL ARCHITECTURES. // FULLSTACK & CYBERSECURITY // "`.
   - Giant watermark stencil monogram `DA//04` in the center.
   - 3-column index grid: PAGES, SIGNATURE / MONOGRAM, CONNECT.

### 7.7 Prohibited Anti-Patterns
- ❌ No generic rounded-2xl cards with default gray border and uniform padding.
- ❌ No standard Lucide-icon-in-a-circle atop every single card.
- ❌ No cyan/blue/purple neon gradients across large background areas.
- ❌ No static, boring vertical lists masquerading as an experience timeline.
- ❌ No default Inter-only typography without editorial tension.
