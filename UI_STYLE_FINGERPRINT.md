## 2. Macro-Composition Fingerprinting (12 Mandatory Dimensions)

1. **Application Shell Archetype**: Perimeter HUD / Floating Island Command Architecture (`fixed top-4 inset-x-4 max-w-6xl mx-auto`). Unlike standard sticky topbars, the perimeter shell frames the viewport, combining a floating top command capsule with a floating bottom-left telemetry widget (`CURRENT DISPATCH // SYSTEM TELEMETRY`) and a floating bottom-right quick-action anchor.
2. **Navigation Model**: Aerodynamic Dual-Track Capsule. Houses personal monogram (`DA//04`), core route anchor links (`DISPATCH`, `DUAL-MODE`, `STACK`, `JOURNEY`, `TERMINAL`), and an unmistakable high-visibility Volt Lime `#D2FF00` pill button (`CV DOSSIER`).
3. **Viewport Zoning & Grid Rhythm**: Asymmetric 12-column architectural grid with generous perimeter negative space (mimicking Lando Norris's gallery-like hero composure). Sections alternate between expansive editorial airiness (`py-28 lg:py-36`) and tight, high-precision technical telemetry clusters.
4. **Primary Information Hierarchy**:
   - Level 0: Flowing Aerodynamic Contours & Wind-Tunnel CFD Streamlines (ambient, non-distracting background depth).
   - Level 1: Perimeter HUD Framing (Top Wordmark + Monogram DA//04 + Pill CTA; Bottom-Left Telemetry Widget).
   - Level 2: Hero Stage (Monumental Mona Sans Display + Brier-style High-Contrast Serif Italic Accent + Dual Slogan).
   - Level 3: Dual-Mode Interactive Architecture ("ON CODE" vs "IN LAB" segmented kinetic switcher).
   - Level 4: Modular Showcase Cards with Notched Tab Badges (hairline borders, bottom protruding year & category badges).
   - Level 5: Contoured Dark Footer (organic curved arch top, dual typography marquee, DA//04 monogram stencil, 3-column index).
5. **Metric Presentation Archetype**: Rejects standard 4-box metric cards. Employs asymmetric engineering telemetry indicators:
   - Live Dispatch Status (`NODE // READY_FOR_DISPATCH`, `LATENCY // SUB-100MS`, `UPTIME // 99.98%`).
   - SVG circuit and streamline traces paired with tabular monospace telemetry chips.
6. **Table / List / Card / Matrix Usage**: Modular Showcase Cards featuring:
   - Fine hairline perimeter borders (`1px solid rgba(255, 255, 255, 0.08)`).
   - Protruding bottom notched tab badge (`bg-surface-elevated border border-white/10 px-3 py-1 font-mono text-[10px] tracking-widest text-accent-lime`).
   - Technical parameter grid (Latency, Protocol, Architecture, Stack tags).
7. **Detail / Drilldown Interaction Model**: Dual-Mode interactive state switching ("ON CODE" fullstack/Next.js/AI vs "IN LAB" SCADA/IoT/Linux Security) with instant kinetic cross-fade and filter reconfiguration; live external repository and deployment deep-links.
8. **Surface Language & Elevation**: Layered Carbon & Aerodynamic Obsidian:
   - Base Ground: `#08090B` (Deep Carbon Obsidian).
   - Streamline Layer: SVG CFD streamlines in `#1A1D24` and `rgba(210, 255, 0, 0.04)`.
   - Card Surface: `#101216` with hairline border `rgba(255, 255, 255, 0.08)`.
   - High-Elevation Island: `#161920` with subtle diffuse rim lighting.
   - Zero murky dropshadows; all depth is achieved through hairline contrast and surface elevation shifts.
9. **Typography Role System & Proportions**:
   - Workhorse Display & Body: **Mona Sans Variable** (by GitHub) — geometric, industrial, modern, with variable stretch and weight (800 for titles, 400/500 for body).
   - Keyword Editorial Accent: **High-Contrast Serif Italic** (ala Brier / Bodoni / Cormorant / Instrument Serif) in italic font-weight 400/500 — applied selectively to punch words ("ARCHITECTURES", "RESILIENT", "FIGHT", "PRECISION").
   - Telemetry & System UI: **JetBrains Mono / Space Mono** (tabular numbers, tracked-out uppercase labels `tracking-[0.22em]`, font-size `10px–12px`).
10. **Density Dial**: 6/10 (Balanced High-Fashion Editorial & Precision Telemetry). Generous breathing room in hero and section headers, high density inside project technical parameter chips.
11. **Motion & Live-State Presentation**:
    - Smooth 200–300ms cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`).
    - Floating subtle wave translation for SVG CFD streamlines (`transform: translate3d(...)`).
    - Kinetic Dual-Mode toggle slider with spring physics.
    - Infinite marquee ticker in footer with reverse hover deceleration.
12. **Signature Visual Motifs**:
    1. Aerodynamic Wind-Tunnel CFD Streamlines & Topographic Vector Contours.
    2. Dual-Mode Architecture ("ON CODE" vs "IN LAB").
    3. Modular Cards with Protruding Bottom Notched Tab Badges.
    4. Floating Solid Volt Lime `#D2FF00` Pill CTA Button.
    5. Contoured Dark Footer with Organic Curved Arch Top and DA//04 Monogram Stencil.
